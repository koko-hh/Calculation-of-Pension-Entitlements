# 重庆企业职工养老金测算

一个纯前端的重庆企业职工基本养老金估算网页。用户数据只在当前浏览器内存中计算，刷新即清空。

## 本地运行与发布

```powershell
pnpm install
pnpm dev
```

生产构建：

```powershell
pnpm build
```

将生成的 `dist` 目录部署到任意静态托管服务即可，例如 GitHub Pages 或 Vercel。发布前运行 `pnpm test`。

若只想在本机直接查看，请双击打开 `dist/index.html`；不要直接打开项目根目录的 `index.html`，它是开发入口，必须通过 `pnpm dev` 运行。

## 政策参数维护

所有可维护参数位于 `src/policy.ts`：计发月数表、当前固定测算参数、已核验的年度养老金计发基数、版本和官方来源。当前页面将养老金计发基数固定为 8240 元/月、账户年记账利率固定为 1.5%。新增年度养老金计发基数时：

1. 只采用社保经办机构或重庆市人社部门可核验的正式口径。
2. 在 `pensionCalculationBaseByYear` 中新增退休年度与月计发基数。
3. 不得将年度社会保险**缴费基数**替代养老金**计发基数**。
4. 更新版本日期和来源链接，并补充相应测试后重新发布。

本工具不计算特殊工种、病退、弹性提前/延迟退休的个案待遇、退休后调待、企业年金、医保待遇、个税或政策性增发。
